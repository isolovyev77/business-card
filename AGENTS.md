# Сайт-визитка: правила для агентов

Статическая одностраничка без сборки: `index.html`, `styles.css`, `script.js`,
`assets/`. Открывается как есть, поэтому любая правка проверяется в браузере,
а не «на глаз в диффе».

## Кейсы

Карточки живут в `<div class="cases-grid">` внутри `<section id="cases">`.
Новая карточка повторяет ту же структуру: обёртка `.case-card`, ссылка-превью
`.case-thumb` с `<img>`, тело `.case-body` с `.case-title`, `.case-description`
и кнопками в `.case-actions`.

**Счётчик в шапке трогать не нужно.** Метрика «N публичных кейсов и материалов»
считается из самой сетки: `syncCasesMetric()` в `script.js` берёт число
`.case-card` и склоняет подпись по числу (21 кейс, 22 кейса, 25 кейсов,
исключение для 11-14). Числа `8` и подписи в `index.html` - это запасной
вариант на случай отключённого JS; их можно оставить как есть, они
перезаписываются при загрузке. Не возвращать в разметку жёстко вбитое число:
именно так метрика однажды отстала от сетки.

Превью кейса: пропорция около 1056×800 (карточка обрезает по `object-fit:
cover` при высоте 280 px), в покое картинка обесцвечена и раскрашивается при
наведении, поэтому она должна читаться и без цвета.

## Два языка

Каждая видимая строка размечена `data-i18n="ключ"`, атрибуты (`aria-label`,
`title`) - через `data-i18n-attr="aria-label:ключ|title:ключ"`. Словарь `I18N`
в начале `script.js` содержит два объекта, `ru` и `en`: ключ, добавленный
только в один из них, оставит на странице текст другого языка.

Строки, которые собираются в коде (например, ответ кнопки «скопировано»),
берутся через `t("ключ")`, а не пишутся литералом.

Кнопки с иконкой переводятся по вложенному `<span data-i18n="...">`: если
повесить `data-i18n` на саму кнопку, `textContent` затрёт SVG.

## Кеш

`index.html` подключает стили и скрипт с версией: `styles.css?v=N`,
`script.js?v=N`. Меняешь файл - поднимаешь номер, иначе у посетителя со старым
кешем разъедется разметка и словарь.

## Тексты

- Фамилия владельца пишется через «е»: **Соловьев**, не «Соловьёв».
- Длинное тире «—» не использовать: дефис, двоеточие, запятая или скобки.

## Публикация

только по просьбе владельца.
